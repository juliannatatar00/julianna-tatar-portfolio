Julianna Tatar – Portfolio website
==================================

Open index.html in any web browser to view the site. No installs needed.

Files
  index.html   The page structure and all the text (each section is a <template>)
  styles.css   Colors, fonts, hover effects and animations
  sections.js  What the interactive parts do (map chapters, open/close sections)
  runtime.js   Small helper that draws the sections; you shouldn't need to edit it
  assets/      Photos and PDFs (résumé, certificate, writing samples)

To put it online, upload this whole folder to any static host
(GitHub Pages, Netlify, Vercel, etc.). Keep the folder structure as is.
